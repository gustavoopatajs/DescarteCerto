## Sobre o projeto

O **DescarteCerto** tem como objetivo facilitar o descarte adequado de resíduos, aproximando a população de pontos de coleta, cooperativas e catadores de materiais recicláveis. A proposta combina informação, localização e cadastro em uma única plataforma, valorizando o trabalho dos catadores e incentivando práticas sustentáveis.

---

## Funcionalidades

- **Mapa:** localização de pontos de coleta e de catadores.
- **Catadores:** seção dedicada à divulgação e ao reconhecimento desses profissionais.
- **Educação:** conteúdo informativo sobre reciclagem e descarte consciente.
- **Cadastro:** página de inscrição de usuários na plataforma.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/gustavoopatajs/DescarteCerto.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd DescarteCerto
   ```

3. Abra o arquivo `index.html` em um navegador. Opcionalmente, utilize a extensão **Live Server** do VS Code para atualização automática durante o desenvolvimento.
